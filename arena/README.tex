\subsection{Overview}

\textbf{SynthOmnicon} is a Python implementation of the \textbf{Unified Synthonicon} framework described in \texttt{QUANTSYNTHONICON.md}. It provides computational tools for analyzing self-organizing chemical systems using \textbf{ten formal primitives} that span molecular, supramolecular, and temporal domains.

\subsection{The Eleven Primitives (v0.4.0)}

The framework is built on eleven core primitives. The first ten cover all classical and quantum systems; the eleventh ($\Omega$) is a quantum extension for topologically protected states --- it is optional and defaults to trivial for all classical synthons.

\begin{enumerate}

\subsubsection{Composition Axioms (v2.1)}

The framework validates against \textbf{seven axioms} --- five composition axioms from QUANTSYNTHONICON.md Section IV, plus two new grounding axioms:

\textbf{Composition Axioms (1-5):}

\begin{enumerate}
    \item \textbf{Axiom 1 (Cyclic Closure):} T\_⋈ + P\_$\pm$ $\rightarrow$ F $\geq$ F\_eth
    \item \textbf{Axiom 2 (Local Grammar Barrier):} G\_ב + $\Gamma$\_\otimes $\rightarrow$ no global propagation
    \item \textbf{Axiom 3 (Cooperative Induction):} Superlinear induction $\rightarrow$ G\_ג reclassification
    \item \textbf{Axiom 4 (Sequential Grammar):} $\Gamma$\_$\rightarrow$ requires D\_$\infty$ or R\_‡
    \item \textbf{Axiom 5 (Criticality):} At criticality, G and D degenerate
\end{enumerate}

\textbf{Grounding Axioms (6-7) --- NEW in v2.1:}
6. \textbf{Axiom 6 (Temporal Grounding):} D\_$\infty$ requires closed cycle with reset mechanism
7. \textbf{Axiom 7 (Cyclic Topology Grounding):} T\_⋈ requires named closing bond/interaction

\subsubsection{Grounding Validation (v2.1) --- NEW}

\textbf{Fix 1: Registration Block on Grounding Warnings}

\begin{itemize}
    \item Synthons with ungrounded primitives can now be blocked from registration
    \item CLI flags: \texttt{--strict-grounding}, \texttt{--override-grounding}, \texttt{--override-reason}
    \item Audit trail logs all grounding overrides with human-provided justifications
\end{itemize}

\textbf{Grounding Status Values:}

\begin{itemize}
    \item \texttt{full} --- All primitives mechanistically grounded
    \item \texttt{partial} --- Some primitives lack grounding (registered with warning)
    \item \texttt{override} --- Registered despite grounding failure (with human override reason)
    \item \texttt{unverified} --- No grounding check performed
    \item \texttt{flagged\_for\_review} --- Marked for manual audit
\end{itemize}

\subsection{The Relational Substrate}

The eleven primitives are \textbf{relational operators}, not intrinsic attributes. Every element of the tuple describes a constraint between entities or a capacity for interaction --- never a monadic property of a system in isolation.

\begin{itemize}
    \item \textbf{F (Fidelity):} Reliability of \emph{constraint satisfaction} relative to a competitor or binding partner. There is no ''intrinsic F'' --- only F relative to a context. The CB{[}7{]} displacement series (6/6 experimental confirmations, \texttt{PRIMITIVE\_PREDICTIONS.md} P-1) was predicted from the ordinal \texttt{$F_{\hbar}$ \textgreater{} F\_eth \textgreater{} $F_{\ell}$} alone, without knowing the intrinsic chemistry of the guests.
    \item \textbf{K (Kinetic):} A barrier to \emph{rearrangement} between states --- requires at least two states and an environment.
    \item \textbf{$\Gamma$ (Grammar):} Partner selection logic by definition. Undefined without a partner.
    \item \textbf{$\Omega$ (TopoIndex):} Topological protection \emph{against perturbations} --- meaningless without an environment to be protected from.
\end{itemize}

\textbf{The algebra enforces this.} Every operation in \texttt{meet / join / tensor / path / lift / pipeline} requires at least one additional operand. There are no unary information generators. The mathematics cannot process ''nothing but the object'' --- it requires a second operand (environment, partner, or target state) to compute anything new.

\textbf{The algebra is asymmetric.} \texttt{path(A-\textgreater{}B) != path(B-\textgreater{}A)}, the F-floor ratchet is directed, \texttt{lift} has no inverse. This is not a limitation; it is what makes predictions \emph{directional} rather than merely topological. The framework encodes directed ordered constraints --- structural realism in operational form.

\textbf{Consequence:} all confirmed predictions (P-1 through P-4 in \texttt{PRIMITIVE\_PREDICTIONS.md}) were driven by ordinal comparisons, not absolute values. Intrinsic scalar properties were not required as inputs. The framework demonstrates that a classification scheme built entirely from directed relational ordinals is sufficient to generate correct quantitative predictions about physical systems.

\subsubsection{Basic Usage}

\begin{lstlisting}[language=Python]
from synthomnicon import (
    Synthon, Dimensionality, Topology, RecognitionMode,
    Polarity, Fidelity, Granularity, InteractionGrammar,
    KineticCharacter, CriticalityPhase,
)

# Create a synthon: carboxylic acid dimer (R₂^2(8) motif)
dimer = Synthon(
    name="carboxylic_acid_dimer",
    dimensionality=Dimensionality.MOLECULAR,       # D_and
    topology=Topology.CYCLIC_BOWTIE,               # T_⋈
    recognition_mode=RecognitionMode.NON_COVALENT, # $R_{\supseteq}$ (H-bonding)
    polarity=Polarity.SELF_COMPLEMENTARY_PSEUDO,   # P_+/-^\psi (pseudosymmetric)
    fidelity=Fidelity.HIGH,                        # $F_{\hbar}$
    kinetic_character=KineticCharacter.FAST,       # K_fast (<60 kJ/mol)
    granularity=Granularity.LOCAL,                 # G_ב
    interaction_grammar=InteractionGrammar.SELECTIVE_AND,  # \Gamma_and(SELECTIVE)
    criticality_phase=CriticalityPhase.SUBCRITICAL,  # Phi_sub
    stoichiometry="1:1",                           # S --- homodimeric
)

print(f"Notation: {dimer.to_notation()}")
# Output: \langleD_wedge; T_bowtie; R_superset; P_pm_pseudo; F_hbar; K_fast; G_beth; Gamma_and(SELECTIVE); Phi_sub; 1:1\rangle
\end{lstlisting}

\subsubsection{Computing Thermodynamic Efficiency (with Kinetic Fidelity)}

\begin{lstlisting}[language=Python]
from synthomnicon.thermodynamics import compute_eta_CP, compute_kinetic_fidelity

# Compute \eta_CP and \xi_CP for the dimer (DeltaG(298K, gas) = -12 kJ/mol)
# Uses effective fidelity: F_effective = F_thermo x F_kinetic

print(f"\eta_CP (efficiency): {result.eta_CP:.2e}")
print(f"\xi_CP (inefficiency): {result.xi_CP:.2f} nats")
print(f"Waste factor: {result.waste_factor:.1e}x Landauer limit")

# Compute kinetic fidelity separately
k_char, f_kinetic = compute_kinetic_fidelity(delta_g_ddagger=45.0)
print(f"Kinetic Character: {k_char.value}, F_kinetic: {f_kinetic:.2f}")
\end{lstlisting}

\subsection{Key Concepts}

\subsubsection{Synthons as Directed Relational Operators}

A \textbf{synthon} is a directed relational operator: a minimal specification of constraint-enforcement capacity defined entirely by its interactions with a compatible context. No primitive in the tuple $\langle D; T; R; P; F; K; G; \Gamma; \Phi; S; \Omega \rangle$ describes an intrinsic property of an isolated object. $F$ is a competitive displacement rank --- there is no $F_\hbar$ in isolation, only $F_\hbar$ relative to a specified competitor set. $K$ is a barrier relative to an environmental driving force. $\Gamma$ is partner-selection logic that presupposes a partner. A tuple without a context encodes interaction affordances --- what constraints it can enforce, against which partners, at what scale --- never the constitution of a substance.

\subsubsection{Composable Design Pipeline}

\begin{lstlisting}[language=bash]

  --step meet:OTHER \
  --step lift:temporal \
  --step path:TARGET:xi_tolerance=1.5 \
  --step tensor:THIRD
\end{lstlisting}

Writer+Maybe monad: accumulates $\Delta$\xi\_CP across all steps; BLOCKED steps are logged and the pipeline continues from the last valid state. Prints a full trace with step-by-step tuple diffs and cumulative costs.

\subsubsection{Decomposition Algebra}

\begin{lstlisting}[language=bash]
# Cofactor --- given composite ~= tensor(A, B), reconstruct B given A

# Birkhoff principal decomposition --- join-irreducible atoms
syncon decomp SYNTHON_NAME

# Project onto primitive subspace
syncon project SYNTHON_NAME --keys Phi,Omega,T

\texttt{cofactor} reports per-axis roles: BOTTLENECK, CONTRIBUTOR, EXPLAINED, PASSTHROUGH, or CONFLICT. \texttt{principal\_decomp} factors into named atoms (\texttt{atom{[}F=...{]}}, \texttt{atom{[}K=...{]}}, \texttt{atom{[}G=...{]}}, \texttt{skeleton(...)}) that compose back to the original under join.
